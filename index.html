CENTRAL CLAIM

Our learner—not the agent—is the primary object of improvement.

Correctness evidence, revision guidance, model opinion, and approval judgment answer different questions and permit different actions.

Why this belongs in today’s curriculum

Four results. One emerging engineering workflow.

The module does not treat these papers as interchangeable examples. Each identifies a different failure surface and motivates a directly assessed learner action.

01 · EVALPLUS

Generation ≠ correctness

HumanEval+ expands tests by 80×. Across 26 models, stricter evaluation lowers pass@k by as much as 19.3–28.9% and can reverse rankings.

Teaching move Strengthen a weak oracle with boundaries and mutations; narrow the claim after a counterexample.

Liu et al., NeurIPS 2023
02 · SWE-AGENT

Capability depends on interfaces

An LM-oriented agent–computer interface resolves 12.47% of 2,294 SWE-bench tasks and gives a 64% relative gain over a shell-only agent on the Lite split.

Teaching move Analyze unrestricted and bounded interface contracts while holding the task fixed; distinguish interface evidence from model-quality claims.

Yang et al., NeurIPS 2024
03 · CLEVER

Specification → machine check

For 161 curated Lean tasks, specification equivalence and implementation correctness must both be proved. Current pipelines solve at most one end-to-end.

Teaching move Validate intent before implementation evidence; a checker can certify the wrong property.

Thakur et al., NeurIPS 2025
04 · RELOC

Generation becomes iterative search

Code improvement becomes drafting, neighborhood generation, candidate evaluation, and incumbent update. Revision distance guides search when test rewards are sparse.

Teaching move Record candidate states and use an explicit revise, accept, or escalate stop rule.

Lyu et al., NeurIPS 2025

The technical concept

An evidence-to-approval lifecycle learners can inspect.

The oracle is independent when it is not copied from the candidate or accepted from the model’s explanation. Passing supports only the named property in the named environment; verified is not approved.

What this resource contributes

Not a fifth algorithm—a teachable integration.

Self-improving-agent work improves generation and search. This resource improves the engineer’s evidence, claim calibration, and approval judgment.

  1. 01
    Four signal classes

    Correctness evidence, revision guidance, model opinion, and approval judgment are never collapsed into one score.

  2. 02
    Observable learning

    Evidence ledgers, counterexamples, scoped claims, and decision records replace prompt fluency as assessment evidence.

  3. 03
    Deliberate boundary

    Model training, RL, inference-time search, MCTS, prompt optimization, memory, and meta-agents are outside this module.

  4. 04
    Reproducible access

    A prepared candidate produces the central result without model access, API cost, or network variability.

Candidate + weak oracle

Counterexample + revision

Add boundary and mutation cases, preserve evidence, and calibrate the claim.

100–125

Architecture + approval

Compare test-equivalent systems and make a separate accountable decision.
