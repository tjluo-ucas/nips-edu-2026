# Two Complementary Teaching PDFs

The slide set has two synchronized, 26-page PDF views. They serve different
teaching purposes and should be used together.

## Classroom projection deck

`verifier_feedback_loops.pdf` is the concise 16:9 learner-facing deck. Use it
for live projection, staged disclosure, classification prompts, lab handoffs,
and the worked counterexample. Stop after “Lab 3: the weak verifier passes”
until learners have committed their own falsification attempt.

## Instructor preparation notes

`Instructor_Notes_Verification_Centered_SE.pdf` is the A4 teacher-facing
companion. Page *n* explains slide *n*: its instructional purpose, an analogy
for explaining the idea, and the intended classroom application. Use it before
class as a facilitation script or during class as a private reference; it is
not intended for projection and does not replace the concise deck.

Together they separate what learners should see from the reasoning instructors
need to teach it accurately. Both use the same title, 26-slide sequence,
four-signal distinction, evidence-to-approval lifecycle, examples, and claim
boundaries.

## Other formats

- `verifier_feedback_loops.html` is the accessible, self-contained browser deck.
- `verifier_feedback_loops.pptx` is the editable classroom version generated
  from `verifier_feedback_loops.md`.
