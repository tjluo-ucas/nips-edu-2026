# Lab 1 - Problem to Executable Intent

## Scenario

A university project team maintains a small ordering service. Users report that promotional discounts sometimes appear inconsistent near the minimum-order threshold. A product owner says: "Please make discounts reliable."

## Task

Before asking an AI agent to write code:

1. Write the **user/scenario/problem/value** statement.
2. Write one user story and one use case.
3. Identify at least three assumptions that require confirmation.
4. Write five acceptance examples, including at least two boundaries.
5. Define what evidence would be sufficient to accept a change.

## Required artifact

```yaml

use_case:
assumptions:
acceptance_examples:
verification_plan:
```

## Reflection
