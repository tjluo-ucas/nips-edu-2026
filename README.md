# NeurIPS 2026 Education course site

Static course site for **Teaching Verification-Centered Software Engineering
with Coding Agents**. The course improves learners' evidence and approval
judgment around agent-produced software; it is not an agent-training course.

Target GitHub Pages URL:

```text
https://tjluo-ucas.github.io/nips-edu-2026
```

## Preview

```bash
python3 -m http.server 8080
```

The site has no build step, external JavaScript, analytics, cookies, fonts, or third-party assets. Publish the repository root with GitHub Pages.

The `downloads/` directory mirrors the current source package's paper and two
complementary teaching PDFs. `verifier_feedback_loops.pdf` is the 16:9
learner-facing projection deck;
`Instructor_Notes_Verification_Centered_SE.pdf` is its page-aligned A4 teacher
companion. Copy refreshed artifacts from the source package before publishing.
